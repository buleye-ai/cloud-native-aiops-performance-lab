## 使用方法

第一次阅读先建立心智模型，第二次按 SOP 模拟事故，第三次关闭答案完成面试复述。

每个主题最终都要回答：

1. 它解决什么问题？
2. 数据和控制流如何运行？
3. 哪些指标可以证明瓶颈？
4. 如何安全复现故障？
5. 生产环境如何止损和回滚？
6. 如何用三分钟讲成面试案例？
