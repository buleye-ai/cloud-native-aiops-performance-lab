# Telegram 学习助手使用指南

在公开频道 [FrogsAndDucks](https://t.me/FrogsAndDucks) 中发送以触发词开头
的内容。直接记录会进入思考日志；AI 生成的内容会先发送到机器人私聊，
确认后才进入博客。

## 功能清单

| 触发词 | 输入 | 结果 |
| --- | --- | --- |
| `#思考` | 一段个人思考 | 原样进入[思考日志](/thoughts/) |
| `#面试` | 面试问题或经验 | 进入思考日志并标记“面试” |
| `#总结` | URL 或原始材料 | 提炼事实、观点、待验证项和结论 |
| `#写作` | 主题、大纲或原始材料 | 生成结构化技术文章候选 |
| `#复盘` | 故障现象、时间线和处置记录 | 生成根因、处置、改进与 SOP |
| `#见解` | 一个观点或需要分析的问题 | 给出正反观点、假设、生产影响和建议 |
| `#帮助` | 无 | 将本功能清单发送到机器人私聊 |

## 使用示例

```text
#思考
记录不是囤积信息，而是把经历变成可以复用的判断模型。
```

```text
#总结 https://example.com/article
```

```text
#复盘
发布后接口 P99 从 200ms 升至 3s，CPU 使用率只有 40%，回滚后恢复。
```

```text
#见解
运维工程师应该如何利用 AI，而不是被 AI 替代？
```

## 审核与发布

```text
频道指令
→ 主 AI 线路
→ 失败时切换备用线路
→ 机器人私聊发送候选
→ 收录博客 / 忽略
→ GitHub 构建并部署
```

`#思考` 和 `#面试` 是直接记录；其余 AI 指令必须经过人工审核。同一条
频道消息按 Telegram `message_id` 去重，工作流重试不会重复生成。

## 随时查看功能

在机器人私聊中使用：

```text
/help
```

也可以点击机器人输入框旁的菜单按钮。频道中发送 `#帮助`，机器人会把
同一份清单发送到管理员私聊。
